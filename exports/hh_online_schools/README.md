# Компании из поиска HH «онлайн школа продажи»

Снимок 8 октября 2026. 432 уникальных работодателя по HH employer ID, 1663 уникальные вакансии. Собраны публичные страницы исходного поиска и того же поиска с обычными фильтрами опыта; авторизация не использовалась.

Архив содержит companies.csv (UTF-8 BOM, название, ID, ссылка на компанию, названия и ссылки вакансий), company_names.txt и report.json. Поиск отображал 3310 вакансий, но доступные страницы и категории опыта дали 1663 уникальные карточки. Полнота исходной выдачи не гарантирована. Компании не классифицированы независимо как онлайн-школы: сохранены все работодатели из результатов запроса, включая смежные компании. Письма и отклики не отправлялись.

## Публичные email

Архив hh_company_contacts_256.zip: проверены все 432 работодателя, найдено 256 уникальных публичных email у 124 компаний; 279 связей компания–email. Включены любые домены, среди них 5 уникальных @mail.ru. CSV содержит источник, метод получения и предполагаемый тип контакта. companies_with_status.csv содержит все 432 компании, включая ненайденные контакты.

Обработка сайтов по ссылкам работодателей и поиск недостающих сайтов через Яндекс/SerpAPI. Суммарное использование SerpAPI в кабинете достигло согласованного лимита 100 запросов, включая прошлые проверки; осталось 150 бесплатных запросов. Контакты не проверены на доставляемость, тип адреса определяется эвристически. Совпадение компании с найденным через поиск сайтом проверено по названию; юридическая идентичность по ИНН не подтверждалась. Полнота контактов не гарантирована. Сообщения не отправлялись.
