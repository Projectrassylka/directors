# База компаний

[Скачать архив ZIP](https://github.com/Projectrassylka/directors/raw/refs/heads/main/exports/companies_1000.zip)

Собрано 8 октября 2026 года из публичного API «Работы России» и опубликованных контактов сайтов компаний.

В архиве: companies.csv (1000 компаний), contacts.csv (2509 email-контактов у 990 компаний), offer_queue.csv (990 предлагаемых офферов), collection_report.json. CSV в UTF-8 с BOM.

Дедупликация по ИНН с резервным ОГРН/кодом работодателя. Источники и категории контактов указаны в таблице. Контакты не являются подтверждёнными адресами директоров; доставка в ящики не проверялась. Письма не отправлены. Архив содержит публичные контактные данные и публикуется по указанию пользователя.
